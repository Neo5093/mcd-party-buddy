# 录屏作战手册 · 90 秒演示视频

> 目标：一条 90 秒视频，让路人 3 秒看懂、30 秒心动、结尾想点 Star。
> 硬约束：演示止于「确认清单页」，不真实下单；全虚构数据，不出现真实地址/手机号。

## 一、工具（任选其一，零安装优先）

| 工具 | 用法 | 适合 |
|---|---|---|
| **Win+Shift+R**（Windows 11 截图工具自带录屏） | 框选 WorkBuddy 窗口 → 录制 → 存 mp4 | 推荐，零安装 |
| OBS Studio | 窗口采集 + 1080p | 要更精细的剪辑时 |
| 剪映（录完剪辑用） | 加字幕/片头片尾/转 GIF | 后期 |

## 二、录制前 10 分钟检查清单

- [ ] **新建 WorkBuddy 对话**，确认 mcd-mcp 连接器已启用
- [ ] **虚构地址已就位**：「北京市东城区王府井大街255号 北京市百货大楼金拱门派对大厦7层」（联系人：小搭），团餐门店已实测可正常返回
  - ⚠️ 录制时地址列表里会出现其他真实地址，**输入台词直接点名"王府井派对大厦那个地址"**，并注意画面里旧地址条目不要停留过久
  - ⚠️ 另有一条测试残留地址（安定门东大街28号），录完视频后在麦当劳 App 里删掉即可
- [ ] 字体调大（对话字号调到截图里能看清）
- [ ] 关闭钉钉/微信/QQ 弹窗通知；隐藏任务栏无关图标
- [ ] 先完整彩排一遍（下面台词已实测可跑通），确认接口响应速度
- [ ] 分辨率 1920×1080，鼠标移动放慢

## 三、分镜脚本（90 秒）

| 时间 | 画面 | 操作 / 台词（直接复制输入） | 要点 |
|---|---|---|---|
| 0-8s | 片头字幕卡 | 大字：「行政订 30 人团建要多久？」→「30 秒。」 | 剪映里做，黑底黄字（#FFC72C） |
| 8-15s | WorkBuddy 对话框 | 输入：**「下周三中午 25 人团建，人均 45，送到王府井派对大厦那个地址」** | 打字速度自然，输完停顿 1 秒再回车 |
| 15-35s | 技能自动跑 | 录「地址确认 → 门店 → 三方案对比表」全过程 | **方案表格完整入镜**，这是全片高光；可适当 1.5x 加速工具调用等待段 |
| 35-40s | 确认清单页 | 停在确认清单，鼠标圈出「应付 ¥955.75 / 人均 ¥38.23 / 节省 ¥466」 | **到这里就停，不点下单** |
| 40-45s | 转场字幕 | 「派对也一样」 | 剪映转场 |
| 45-70s | 新开对话 | 输入：**「想给孩子订个生日派对，北京，下周六，10 个人」** → 录在售活动过滤 → 门店 Top5 → 场次 + 派对黄历 → 确认清单 | 黄历「宜/可/忌」列给 2 秒特写 |
| 70-85s | 片尾卡 | 项目名 + GitHub 地址 +「觉得有用，求个 Star ⭐」 | 剪映做，红黄配色 |
| 85-90s | 彩蛋帧 | 「本视频所有数据均为演示数据」 | 合规声明 |

## 四、剪辑导出

1. 剪映导入 mp4 → 剪掉等待冷场 → 加三段字幕卡（片头/转场/片尾）
2. 导出 **1080p mp4**（传播用：脉脉/小红书/掘金）
3. 再导出一份 **GIF**（≤10MB，剪映导出选 GIF 或用 ffmpeg）放 README 首屏：
   ```bash
   ffmpeg -i demo.mp4 -vf "fps=12,scale=960:-1" -loop 0 docs/demo.gif
   ```
4. GIF 推到仓库后替换 README 里的 TODO 占位

## 五、发布位

- README 首屏 GIF（自动播放，Star 转化主阵地）
- 传播稿视频附件（mp4）
- B 站/视频号可同步发一份（可选）

## 六、常见翻车点

- 团餐预约窗口只有未来 6 天 → 台词用「下周三」而非具体日期，技能会自动对齐窗口
- 真实地址意外入镜 → 必须用虚构地址彩排，正式录前检查一遍地址列表截图
- 接口偶发慢 → 等待段后期加速，不要现场干等
