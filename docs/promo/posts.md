## 三、掘金版（技术向）

**标题：我用麦当劳官方 MCP 写了个团建管家：满减优化 + 派对黄历（1024 参赛）**

**正文框架：**

1. **背景**：麦当劳中国开放了官方 MCP Server（mcp.mcd.cn），33 个工具覆盖点餐/优惠券/积分/团餐/派对预约全链路。我选了条冷门赛道：不做单人点餐推荐（太卷），做组织者视角的双线技能。

2. **架构三原则**：取数交给 MCP，算术交给代码，表达交给 Agent。
   - LLM 口算价格不可靠 → 满折优化由确定性脚本完成（scripts/team_feast.py），下单前再用 calculate-price 核价
   - 纯标准库 MCP 客户端（scripts/mcd_client.py），零依赖

3. **实战发现的有趣细节**（都是文档里没写的）：
   - 团餐满折是阶梯制且与助餐服务联动：保鲜速达 7 折 / 专人分餐 8 折 / 专人摆台 8.5 折
   - 派对场次由门店排期，"下午场"可能根本不存在
   - 预约窗口只有未来 6 天；派对需提前 3 天
   - 开心乐园餐不参与团餐满折

4. **双线演示**：25 人团餐（原价 1352.5 → 实付 955.75，人均 38.23）+ 生日派对预约（成团提示 + 黄历选日）。离线 demo 无需 Token 可跑。

5. **结尾**：1024 参赛中，欢迎 Star / Fork / 提 Issue。
